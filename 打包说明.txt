# 快速打包指南

## 方法1：使用命令行（推荐）

打开命令提示符（CMD），运行：

```bash
cd "c:\Users\Lwz\Desktop\家具图\试试"
npx electron-builder --win --x64
```

## 方法2：使用批处理文件

双击 `打包桌面应用.bat`

## 打包完成后

在 `release` 文件夹中找到：
- `家具图片处理工具 Setup 1.0.0.exe`

将这个文件发给用户即可！

## 用户使用方式

1. 双击安装 .exe 文件
2. 安装完成后，桌面会有快捷方式
3. 双击快捷方式启动程序
4. 代理服务器会自动在后台运行
5. 使用完毕关闭窗口即可

## 注意事项

- 首次打包需要下载 Electron（约150MB），请耐心等待
- 打包后的安装程序约 80-100MB
- 杀毒软件可能会报警，这是正常现象
