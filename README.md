# 家具图片处理工具

自动识别家具图片中的家具信息，并导出为Excel表格。支持网格切割、OCR识别、图片打包下载。

## 功能特点

- 📤 上传家具网格图片
- 🎯 实时网格线预览，可视化切割位置
- ✂️ 自动切割每个家具格子
- 🔍 百度OCR高精度识别家具名称和数量
- 📊 生成Excel表格（横向布局，一排四个产品）
- 🖼️ Excel中直接嵌入家具图片
- ✏️ 可编辑识别结果
- 💾 一键导出Excel文件
- 📦 批量下载所有切割图片（ZIP打包）

## 环境要求

- Node.js 14+
- npm 或 yarn

## 快速开始

### 1. 安装依赖

```bash
npm install
```

### 2. 启动代理服务器

**重要：必须先启动代理服务器才能使用百度OCR功能**

双击运行 `启动代理服务器.bat`，或在命令行中执行：

```bash
node proxy-server.js
```

看到以下提示说明启动成功：
```
========================================
  百度OCR代理服务器已启动！
  监听端口: 3000
  代理地址: http://localhost:3000
========================================
```

**保持这个窗口打开！**

### 3. 启动前端项目

打开新的命令行窗口，执行：

```bash
npm run dev
```

浏览器会自动打开 http://localhost:5173

## 配置百度OCR

### 获取API密钥

1. 访问 [百度智能云控制台](https://console.bce.baidu.com/ai/#/ai/ocr/overview/index)
2. 注册/登录百度智能云账号
3. 创建应用，选择"通用文字识别"
4. 获取 **API Key** 和 **Secret Key**

### 在工具中配置

1. 在工具界面中找到 API Key 和 Secret Key 输入框
2. 填入你获取的密钥
3. 密钥会自动保存在浏览器中，下次无需重新填写

### 免费额度

- 百度OCR每天有 **500次** 免费调用额度
- 超出后需要付费或等待第二天重置

## 使用说明

### 基本流程

1. **上传图片**
   - 点击"📁 选择家具图片"按钮
   - 选择包含多个家具的网格图片

2. **调整网格**
   - 设置网格列数（横向有几个家具）
   - 设置网格行数（纵向有几行）
   - 红色虚线会实时显示切割位置
   - 调整数字确保每个格子只包含一件家具

3. **开始识别**
   - 点击"🔍 开始识别"按钮
   - 等待百度OCR识别完成
   - 识别过程中会显示进度

4. **编辑结果**
   - 检查识别的家具名称、数量
   - 手动修改错误的识别结果
   - 填写价格信息

5. **导出数据**
   - **导出Excel**：点击"📊 导出Excel表格"
     - 横向布局，一排四个产品
     - 图片直接嵌入Excel中
     - 列顺序：图片 | 名称 | 数量 | 单价
   - **下载图片**：点击"🖼️ 下载所有图片"
     - 所有切割图片打包成ZIP文件
     - 解压后在"家具图片"文件夹中

## Excel导出格式

导出的Excel表格采用横向布局：

```
| 图片 | 名称 | 数量 | 单价 | 图片 | 名称 | 数量 | 单价 | 图片 | 名称 | 数量 | 单价 | 图片 | 名称 | 数量 | 单价 |
|------|------|------|------|------|------|------|------|------|------|------|------|------|------|------|------|
| 🖼️  | 沙发 |  2   | 3000 | 🖼️  | 茶几 |  1   | 800  | 🖼️  | 床   |  1   | 5000 | 🖼️  | 衣柜 |  1   | 4000 |
```

特点：
- 一排显示4个产品
- 图片尺寸：100x60像素（长方形）
- 行高：60像素（与图片高度一致）
- 表头灰色背景，数据居中对齐

## 技术栈

- **Vue 3** - 前端框架
- **Vite** - 构建工具
- **Canvas API** - 图像处理
- **百度OCR API** - 文字识别
- **ExcelJS** - Excel文件生成（支持图片）
- **JSZip** - ZIP文件打包
- **Node.js** - 代理服务器

## 故障排除

### 问题1：提示"百度OCR调用失败"
- 检查代理服务器是否启动
- 检查API Key和Secret Key是否正确
- 查看代理服务器窗口是否有错误信息
- 确认网络连接正常

### 问题2：识别效果不好
- 确保图片清晰，分辨率足够
- 调整网格行列数，确保每个格子只包含一件家具
- 识别后可以手动修改错误的结果

### 问题3：代理服务器启动失败
- 确保已安装Node.js（运行 `node -v` 检查）
- 检查3000端口是否被占用
- 尝试以管理员身份运行

### 问题4：图片下载不完整
- 使用"下载所有图片"功能会打包成ZIP
- 如果浏览器提示是否允许多个下载，请点击"允许"
- ZIP文件包含所有图片，不会遗漏

### 问题5：Excel中图片显示异常
- 确保使用Excel 2016或更高版本打开
- 如果图片位置偏移，可能是Excel版本兼容性问题
- 建议使用WPS Office或最新版Microsoft Excel

## 注意事项

- 首次使用需要配置百度OCR密钥
- 代理服务器必须保持运行状态
- 百度OCR免费版限制2QPS（每秒2次请求）
- 识别准确度取决于图片质量
- Excel文件中的图片是真实嵌入的，可以直接查看
- 建议使用Chrome或Edge浏览器以获得最佳体验
