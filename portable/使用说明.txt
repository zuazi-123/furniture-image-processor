# 家具图片处理工具 - 使用说明

## 📦 文件结构

```
furniture-portable/
├── 一键启动.bat              ← 双击这个启动所有服务
├── 使用说明.txt              ← 本文件
├── 家具图片处理工具/
│   ├── 启动.bat              ← 单独启动应用（需手动启动UMI-OCR）
│   ├── server.js             ← Web服务器
│   ├── node.exe              ← Node.js运行环境
│   ├── dist/                 ← 应用文件
│   └── node_modules/         ← 依赖包
└── UMI-OCR/                  ← OCR识别引擎
    ├── Umi-OCR.exe           ← UMI-OCR主程序
    └── UmiOCR-data/          ← 数据文件
```

## 🚀 快速开始

### 方式1：一键启动（推荐）

1. 双击 `一键启动.bat`
2. 等待程序自动启动
3. 浏览器会自动打开应用页面
4. 开始使用！

### 方式2：分别启动

1. 先启动 UMI-OCR：
   - 进入 `UMI-OCR` 文件夹
   - 双击 `Umi-OCR.exe`

2. 再启动应用：
   - 进入 `家具图片处理工具` 文件夹
   - 双击 `启动.bat`

## 📖 使用教程

### 图文版功能

1. **选择分类**：点击顶部的家具分类标签
2. **上传图片**：
   - 方式1：点击"批量选择家具图片"按钮
   - 方式2：拖拽图片到拖放区域
3. **绘制裁剪框**：在图片上拖动鼠标绘制矩形框
4. **自动生成网格**：设置行列数，自动生成多个裁剪框
5. **开始识别**：点击"开始识别"按钮
6. **查看结果**：识别完成后，在下方表格中查看结果
7. **导出数据**：
   - 导出Excel：包含所有识别数据
   - 下载图片：打包下载所有裁剪后的图片

### 纯图版功能

1. **上传图片**：选择多张图片
2. **调整顺序**：拖动图片调整排列顺序
3. **逐张裁剪**：为每张图片绘制裁剪框
4. **预览拼接**：查看最终拼接效果
5. **导出图片**：保存拼接后的图片

### 拖拽上传功能

1. **拖入图片**：将图片拖到拖放区域
2. **选择分类**：在弹出窗口中选择要放入的分类
3. **点击确定**：图片会保存到该分类
4. **导入识别**：切换到对应分类，点击"导入拖入图片"按钮

## ⚙️ 系统要求

- **操作系统**：Windows 7/8/10/11（64位）
- **内存**：建议 4GB 以上
- **磁盘空间**：至少 500MB 可用空间
- **浏览器**：Chrome、Edge、Firefox 等现代浏览器

## ❓ 常见问题

### Q1：双击启动后没有反应？

**解决方案：**
1. 检查是否有杀毒软件拦截
2. 右键点击 `一键启动.bat`，选择"以管理员身份运行"
3. 检查 8888 端口是否被占用

### Q2：提示"无法连接到UMI-OCR服务"？

**解决方案：**
1. 确认 UMI-OCR 已启动（查看任务栏是否有图标）
2. 打开 UMI-OCR，检查 HTTP 服务是否启用
3. 确认端口为 1224

### Q3：识别结果不准确？

**解决方案：**
1. 确保图片清晰度足够
2. 裁剪框尽量贴合文字区域
3. 避免裁剪框包含过多背景

### Q4：如何关闭程序？

**解决方案：**
1. 关闭浏览器标签页
2. 关闭命令行窗口（黑色窗口）
3. 关闭 UMI-OCR（右键任务栏图标 → 退出）

### Q5：可以在其他电脑上使用吗？

**解决方案：**
可以！这是便携版，直接复制整个文件夹到其他电脑即可使用。

### Q6：如何更新版本？

**解决方案：**
1. 下载新版本的压缩包
2. 解压覆盖旧文件
3. UMI-OCR 可以保留不更新

## 🔧 高级设置

### 修改端口

如果 8888 端口被占用，可以修改端口：

1. 用记事本打开 `家具图片处理工具\server.js`
2. 找到 `const PORT = 8888`
3. 修改为其他端口，如 `const PORT = 9999`
4. 保存文件

### 配置 UMI-OCR

1. 启动 UMI-OCR
2. 点击"全局设置"
3. 找到"HTTP服务"选项
4. 确保启用，端口为 1224
