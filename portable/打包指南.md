# 便携版打包指南

## 📦 打包步骤

### 步骤1：构建项目

```bash
# 在项目根目录执行
npm run build
```

这会生成 `dist` 文件夹，包含所有前端文件。

### 步骤2：运行打包脚本

```bash
# 双击运行
打包便携版.bat
```

脚本会自动：
1. 构建项目
2. 创建便携版目录结构
3. 复制所有必要文件
4. 安装 express 依赖

### 步骤3：准备 Node.js 便携版

#### 方式1：下载官方便携版

1. 访问 https://nodejs.org/dist/v20.11.0/
2. 下载 `node-v20.11.0-win-x64.zip`
3. 解压到项目根目录的 `node-portable` 文件夹
4. 重新运行打包脚本

#### 方式2：使用系统 Node.js

如果用户电脑已安装 Node.js，可以跳过此步骤。
但需要在使用说明中注明系统要求。

### 步骤4：添加 UMI-OCR

1. 下载 UMI-OCR：
   - 访问 https://github.com/hiroi-sora/Umi-OCR/releases
   - 下载最新版本（如 Umi-OCR_Paddle_v2.1.5.7z）

2. 解压 UMI-OCR：
   ```
   furniture-portable/
   └── UMI-OCR/
       ├── Umi-OCR.exe
       └── UmiOCR-data/
   ```

### 步骤5：测试

1. 进入 `furniture-portable` 文件夹
2. 双击 `一键启动.bat`
3. 测试所有功能是否正常

### 步骤6：压缩打包

使用 7-Zip 或 WinRAR 压缩：

```
furniture-portable.7z
或
furniture-portable.zip
```

**推荐设置：**
- 格式：7z
- 压缩等级：标准
- 分卷大小：100MB（如果文件太大）

## 📁 最终目录结构

```
furniture-portable/
├── 一键启动.bat                    ← 用户双击这个
├── 使用说明.txt
├── app/                            ← 应用程序文件夹
│   ├── 启动.bat
│   ├── server.js
│   ├── node.exe                    ← Node.js 运行环境
│   ├── dist/                       ← 前端文件
│   │   ├── index.html
│   │   ├── admin.html
│   │   └── assets/
│   └── node_modules/               ← express 依赖
│       └── express/
└── UMI-OCR/                        ← OCR 引擎
    ├── Umi-OCR.exe
    └── UmiOCR-data/
```

## 📊 文件大小估算

- 家具图片处理工具：~50MB
  - dist/: ~5MB
  - node.exe: ~20MB
  - node_modules/: ~25MB

- UMI-OCR：~150MB

- **总计：~200MB**
- **压缩后：~100MB**

## ⚠️ 注意事项

### 1. 许可证问题

- 确保 UMI-OCR 的使用符合其开源许可证
- 在使用说明中注明 UMI-OCR 的来源和许可证

### 2. 杀毒软件

- 某些杀毒软件可能误报
- 建议在使用说明中提醒用户添加信任

### 3. 系统兼容性

- 测试不同 Windows 版本（Win7/10/11）
- 确保在没有管理员权限的情况下也能运行

### 4. 更新策略

**方式1：完整包更新**
- 发布新版本时，重新打包整个便携版
- 用户下载新版本覆盖旧版本

**方式2：增量更新**
- 只更新 `家具图片处理工具` 文件夹
- UMI-OCR 保持不变

## 📝 版本管理

建议使用语义化版本号：

- v1.0.0：首个正式版本
- v1.0.1：Bug 修复

## 📞 技术支持

如果用户遇到问题，常见解决方案：

1. **端口被占用**：修改 server.js 中的端口
2. **UMI-OCR 无法启动**：检查是否缺少 VC++ 运行库
3. **浏览器不兼容**：建议使用 Chrome 或 Edge
